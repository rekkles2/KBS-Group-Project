## Method

1. Audit all input objects, CSV agreement, snapshots, evidence and input SHA-256 hashes.
2. On original unique directed multirelational edges, total degree = incoming + outgoing (self-loop contributes two). Rank independently per `entity_type`, breaking ties by lexical QID. Require true eligibility, no flags, valid type and positive degree.
3. Initially choose `min(n,20,max(2,ceil(.05*n)))` per type with at least two eligible nodes. `--top-k-max` is the initial cap. Double ranked prefixes deterministically only if the candidate pool is insufficient; constraints remain unchanged.
4. Enumerate pair-local transpositions of hub pairs. For each original incident edge apply the same pair mapping to both endpoints. Many candidate-specific mappings are possible; the final overlay is **not a single global graph permutation**. This is the requested additive pairwise adaptation.
5. Require original directed relation-role evidence for each replacement donor with the same counterpart general type. This checks an empirical domain/range signature, not a formal ontology or factual truth. Exclude self-loops, all original triples across snapshots, conservatively projectable positive triples from all QA, and duplicate candidates.
6. Choose exactly `round_half_even(Decimal(original_edge_count)*Decimal(ratio))`. The default is 774 additional edges (10.003877% of 7,737 due to integer rounding), yielding 8,511 edges. Sample with seed 42 using round-robin types and relations, seeded within buckets. This balance differs from original-distribution-proportional sampling.
7. Preserve all original objects unchanged. Append explicitly synthetic edges with empty `evidence`, pair/source-edge/swap provenance, and original QA references only under `injection_provenance`. Original snapshot lists remain annotation observations; injected lists indicate synthetic overlay visibility. Original node observation lists remain unchanged even when an overlay endpoint has no original observation in that snapshot.

Missing edges are not necessarily false. Every injected edge has `value: "fake"`, meaning synthetic construction, and a separate `factual_verification.status: "unresolved"`. The existing provenance status `unverified` is retained unchanged for compatibility. No real Wikidata node or original edge receives the synthetic class label. Zero injected claims have been independently established true or false. Queries and answers are preserved, and no attack-effectiveness claim is made.

## Training/construction labels

`outputs/edge_injection_labels.csv` labels every graph edge using `edge_index` plus the directed triple: `is_synthetic_edge=1` and `synthetic_class=fake` identify injected edges; original edges have 0/original. `factual_verification_status` is separate (unresolved for this injection; not_adjudicated for original statements).

`outputs/node_injection_labels.csv` covers every QID: `is_synthetic_node=0` for all original entities in this Task 1; `incident_to_synthetic_edge` is a distinct binary participation label, with synthetic in/out/total degree. Node incidence is not a label of fictitious identity or factual falsehood. Both CSVs are generated by the canonical pipeline, validated in tests, and checksummed in the manifest. Original node objects remain unchanged.

## Revised diagnostics

From the repository root, `python hub_injection/tools/audit_facts_v2.py --original original_KG/pat_kg_merged.json` audits all injected claims locally and reuses a bounded evidence cache; `--fetch` is an optional network refresh. `python hub_injection/tools/analyze_structure_v2.py --original original_KG/pat_kg_merged.json` performs the ten-seed structural comparison. These optional commands replace their corresponding diagnostic reports. Default graph generation uses neither network nor timestamps. The structural outcome is mixed: augmented alternative paths are higher under the conditional baseline, but original-topology support is not uniformly stronger. These untyped metrics cannot verify a relation or attack success.

The bounded live factual sample covers 86/774 claims (11.1%); 688 have no external current-statement lookup. All 774 receive local graph/QA checks, and all remain unresolved. Per-snapshot edge counts overlap and cannot be summed to the number of unique injected triples. Relation buckets start in deterministic sorted order before seeded shuffling; exhausted buckets are skipped while remaining buckets are sampled. The sort is required to make sampling independent of caller input order.

For optional clean-copy verification, use `hub_injection/tools/package_release_v2.py` from the repository root with explicit `--graph`, `--entities` and `--check-clean` paths; the evidence file's parent directory must already exist. See the [portable reproduction guide](reports/REPRODUCTION_v2.md) for the procedure. This verifies independent-copy regeneration without hard links or stale outputs. Inputs can be stored anywhere when CLI paths and `PAT_KG_INPUT_DIR` for tests are supplied. Original datasets are omitted from portable ZIPs with required-input SHA-256 manifests.

## Relationship to prior work

[LogicPoison](https://arxiv.org/html/2604.02954), Sections 4.1–4.3, ranks within-type document frequencies, combines global hubs and query-specific entities, then rewrites corpus mentions via a cyclic bijection. This project operates on an existing QA-projection graph, ranks explicit graph degree, uses pairwise swaps, and appends a budgeted overlay without rewriting source text or removing edges. It is an adaptation, not an exact reproduction. [PAT-Questions](https://arxiv.org/html/2402.11034v2), Sections 3–4, generates present-anchored QA using Wikidata/SPARQL. Local annotation-observation snapshots do not reconstruct statement qualifiers or validity intervals.
